# העברת SMS אוטומטית — הגדרת OTP ללא ידיים

מדריך הגדרה לסוכן: איך לגרום לאוטומציה של Nifraim לטפל בקודי האימות (OTP) של פורטלי חברות הביטוח **בלי שתצטרך להזין כלום**.

---

## איך זה עובד

1. הפורטל (מגדל, הפניקס, וכו') שולח SMS עם קוד אימות **לטלפון האישי שלך**
2. הטלפון שלך מזהה את ההודעה ומעביר אותה אוטומטית לשרת של Nifraim דרך האינטרנט
3. השרת קולט את הקוד, מחלץ אותו, ומזין אותו לפורטל במקומך
4. ההורדה ממשיכה ומסתיימת לבד

**הטלפון לא צריך להיות באותה רשת WiFi כמו המחשב.** הוא יכול להיות בכל מקום בעולם — סלולר או WiFi.

הגדרה חד-פעמית. אחרי שהגדרת — זה עובד לכל הפורטלים שלך, לכל הריצות, לעולמים (עד שתרצה להחליף).

---

## שלב 1 — קבלת כתובת ה-Webhook שלך

1. פתח את המערכת בדפדפן והתחבר
2. תפריט עיגול (CircleMenu) למטה → **הגדרות**
3. בחלון "הגדרות חשבון" → קטע **"העברת SMS אוטומטית"** → לחץ **"הגדרת העברת SMS"**
4. במודאל שנפתח → לחץ **"צור כתובת מאובטחת"**
5. תראה כתובת דמוית:
   ```
   https://nifraim-production.up.railway.app/api/portal-automation/phone-forward/AbCd1234...
   ```
6. **העתק את הכתובת**. תשתמש בה בשלב הבא.

> שמור על הכתובת — היא סודית. מי שיש לו אותה יכול להזריק קודי OTP לחשבון שלך. אם דלפה, לחץ **"החלף מפתח"** במודאל כדי להמציא חדשה ולעדכן בטלפון.

## שלב 2א — הגדרת אנדרואיד (SMS Forwarder)

זמן הגדרה: כ-3 דקות.

### התקנה
התקן מ-Google Play את האפליקציה **SMS Forwarder** (חיפוש: "SMS Forwarder" של frzinapps — האייקון הוא משולש כחול עם חץ לבן).

### הגדרת כלל
1. פתח את האפליקציה
2. הרשאות: אשר גישה ל-SMS, התראות ורקע
3. הקש **"+"** ליצירת כלל חדש (`New Forwarding Rule`)
4. **שם הכלל**: `Nifraim OTP` (או כל שם שתבחר)
5. **תנאי שליחה**:
   - `From / Sender contains` — השאר ריק (לקבל מכל המספרים)
   - **או** `Body contains` — מילה שתופיע בכל ה-SMS הרלוונטיים (למשל `Migdal`, `Phoenix`, `מגדל`)
6. **סוג היעד (Forward to)**: בחר **Webhook (HTTP POST)**
7. **URL**: הדבק את הכתובת מהשלב הקודם
8. **שיטה (Method)**: `POST`
9. **Content Type**: `application/json`
10. **תוכן (Body)**:
    ```json
    {"message":"[content]"}
    ```
    כאן `[content]` הוא משתנה של האפליקציה שמתחלף בתוכן ה-SMS האמיתי. אם השם בעברית/אנגלית שונה בגרסת האפליקציה שלך — השתמש במה שמופיע בעזרה של האפליקציה.
11. שמור והפעל את הכלל (toggle).

### חשוב באנדרואיד
- **בטל אופטימיזציית סוללה** עבור האפליקציה (Settings → Apps → SMS Forwarder → Battery → Unrestricted) — אחרת המערכת תרדים אותה והכלל לא יפעל.
- **השאר את האפליקציה פועלת ברקע** — אל תכבה אותה ב-task switcher.

## שלב 2ב — הגדרת אייפון (Shortcuts)

זמן הגדרה: כ-5 דקות. לא צריך להתקין שום אפליקציה — Shortcuts בנוי לתוך iOS.

### יצירת אוטומציה
1. פתח את אפליקציית **Shortcuts** (מותקנת כברירת מחדל)
2. עבור ללשונית **Automation** (תחתית המסך)
3. הקש **"+"** (פינה ימנית עליונה)
4. בחר **"Create Personal Automation"**
5. גלול ובחר את הטריגר **"Message"**
6. **Sender**: השאר ריק (לקבל מכולם)
7. **Message Contains**: כתוב מילה שתופיע ב-SMS הרלוונטי (למשל `Migdal`, `Phoenix`, `מגדל`, `קוד אימות`)
8. **חשוב**: בחר **"Run Immediately"** (לא "Run After Confirmation"!) → Next
9. במסך הבא: הוסף פעולה **"Get Contents of URL"**

### הגדרת ה-POST
10. **URL**: הדבק את הכתובת מהשלב הקודם
11. הקש על החץ הקטן מתחת ל-URL כדי לפתוח את ההגדרות המתקדמות:
    - **Method**: שנה ל-`POST`
    - **Request Body**: שנה ל-`File`
12. בשדה ה-File שנפתח:
    - **הקש על השדה** (אל תכתוב בו!)
    - מבחר משתנים (Variable Picker) ייפתח אוטומטית
    - בחר **"Shortcut Input"** — צריך להופיע כ**צ'יפ צבעוני כחול/סגול**, לא כטקסט רגיל!
13. הקש **Done**

### אם עדיין לא עובד — נסה JSON במקום File
1. במקום `Request Body: File`, בחר `Request Body: JSON`
2. הקש **"Add new field"** → **Text**
3. **Key**: `message`
4. **Value**: הקש בשדה הערך, **מחק את הטקסט שיש שם**, ובמקבץ המשתנים מעל המקלדת **הקש על הצ'יפ "Shortcut Input"**

### חשוב באייפון
- האוטומציה חייבת להיות **enabled** בלשונית Automation (toggle ירוק)
- ב-iOS 17+ ייתכן שתראה התראה קצרה כשהאוטומציה רצה. זה תקין.

## שלב 3 — חיבור הקרדנשייל ל"הטלפון האישי שלי"

עכשיו תגיד למערכת להשתמש בנתיב הזה במקום מספר Twilio או הזנה ידנית.

1. בלשונית הפורטלים (אוטומציה), לחץ על הקרדנשייל של מגדל / הפניקס / וכו' → **עריכה**
2. בקטע **"איך OTP יגיע למערכת?"** → בחר **"הטלפון האישי שלי"**
3. שמור

## שלב 4 — בדיקה

### בדיקה 1: השרת קולט (ללא טלפון)
במודאל "העברת SMS אוטומטית":
1. בשדה הבדיקה הקלד: `קוד אימות לבדיקה: 123456`
2. הקש **"בדיקה"**
3. אמור להופיע: **"קוד שזוהה: 123456 — המערכת תקבל את ההודעה כרגע"** ✅

### בדיקה 2: הטלפון מעביר נכון
שלח לעצמך SMS מטלפון אחר (חבר, בן/בת זוג, או דרך textbelt.com) שמכיל את מילת הטריגר + מספר בן 6 ספרות.
דוגמה: `Migdal: 482917`

תוך 2 שניות, חזור לאפליקציה → מודאל "העברת SMS אוטומטית" → אמור להופיע ב"Recent received" (אם זמין) — או פשוט תנסה ריצה אמיתית בבדיקה הבאה.

### בדיקה 3: ריצה אמיתית מקצה לקצה
1. בלשונית הפורטלים → לחץ **"הרץ עכשיו"** על מגדל
2. **אל תיגע בטלפון** — שב ותסתכל
3. תוך כמה שניות הפורטל ישלח SMS לטלפון שלך
4. הטלפון יעביר אוטומטית למערכת
5. הריצה ממשיכה לבד ומסתיימת ב-`success` עם קובץ הורדה
6. הלשונית "השוואה" תתעדכן אוטומטית

אם הצלחת — סיימת. זה ימשיך לעבוד עד שתרצה להחליף מפתח.

## פתרון בעיות

| תסמין | סיבה אפשרית | פתרון |
|---|---|---|
| הריצה תקועה ב-"awaiting_otp" 90 שניות אז כושלת | הטלפון לא העביר את ה-SMS | בדוק את הכלל באפליקציה (אנדרואיד) או את ה-Automation (אייפון). ודא ש-toggle ירוק. |
| הגוף של ה-SMS מופיע ב-Recent received כטקסט מילולי "shortcut input" / "Shortcut Input" | הקלדת את המילים במקום להוסיף את המשתנה הקסום | חזור על שלב 12 — תוודא שזה צ'יפ צבעוני, לא טקסט |
| 422 Unprocessable Entity בלוגים | פורמט בקשה לא תקין (פגום ב-Android Forwarder) | ודא Content-Type: `application/json` והגוף הוא `{"message":"..."}` |
| הריצה עובדת פעם ראשונה ונכשלת אחר כך | הטלפון נכבה / Battery optimization מקטרת | הוסף את אפליקציית ה-Forwarder לרשימת "Unrestricted" באנדרואיד; ודא שה-Shortcut לא מבקש אישור |
| מקבל 200 אבל אין `otp_code` במסד הנתונים | ה-SMS לא הכיל קוד בן 4-8 ספרות | בדוק את גוף ה-SMS — הregex מחפש `\b(\d{4,8})\b` (גבולות מילים) |
| העברתי לטלפון חדש — לא עובד | המפתח עדיין מקושר לטלפון הישן | במודאל ההגדרה → **"החלף מפתח"** → עדכן את הכתובת באפליקציה בטלפון החדש |

## אבטחה

- **המפתח בכתובת = סיסמה**. שמור עליה. אם דלפה: החלף מפתח דרך המודאל.
- אורך 256 ביט (≈43 תווים) — לא ניתן לנחש בכוח גס.
- המערכת לא מאמתת שה-SMS באמת בא מהפורטל — היא בוטחת בכל מה שמגיע למפתח. לכן: אל תשתף את הכתובת.
- כל בקשה לוגית נשמרת בטבלת `otp_inbox` עם חותמת זמן.
